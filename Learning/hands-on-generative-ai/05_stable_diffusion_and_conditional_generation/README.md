# Chapter 05: Stable Diffusion and Conditional Generation

This chapter details Stable Diffusion, which performs diffusion in a low-dimensional *latent space* instead of pixel space, drastically reducing resource requirements. We also study conditioning via CLIP and Classifier-Free Guidance.

---

## 🔑 Key Concepts
*   **Latent Diffusion Models (LDM)**
*   **The VAE Encoder/Decoder in Stable Diffusion**
*   **CLIP Text Encoder for prompts conditioning**
*   **Classifier-Free Guidance (CFG) scale tuning**
