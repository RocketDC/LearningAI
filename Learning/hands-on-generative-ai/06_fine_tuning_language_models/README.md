# Chapter 06: Fine-Tuning Language Models

To customize LLMs, we fine-tune them. This chapter explores Supervised Fine-Tuning (SFT), parameter-efficient methods like LoRA and QLoRA, and preference alignment techniques (RLHF, DPO).

---

## 🔑 Key Concepts
*   **Supervised Fine-Tuning (SFT)**
*   **LoRA (Low-Rank Adaptation) and QLoRA theory**
*   **Preference Tuning (RLHF, DPO, KTO)**
*   **PEFT (Parameter-Efficient Fine-Tuning) library integration**
