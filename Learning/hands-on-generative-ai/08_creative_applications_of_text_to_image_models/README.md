# Chapter 08: Creative Applications of Text-To-Image Models

Generative media offers vast creative potential. This chapter shows you how to build pipelines for image editing tasks: image-to-image conversion, inpainting (editing sections), outpainting (extending borders), and instruct-based edits.

---

## 🔑 Key Concepts
*   **Image-to-Image (img2img) translation**
*   **Inpainting (erasing and filling image parts)**
*   **Outpainting (canvas extension)**
*   **InstructPix2Pix (modifying images using textual instructions)**
