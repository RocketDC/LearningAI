# Chapter 04: Diffusion Models

This chapter breaks down the mechanics of Diffusion Models, explaining how they generate images by iteratively removing noise. We cover the forward process (adding noise) and the reverse process (denoising).

---

## 🔑 Key Concepts
*   **Forward Diffusion Process (Markov Chain)**
*   **Denoising Diffusion Probabilistic Models (DDPM)**
*   **U-Net architecture for noise estimation**
*   **Denoising Diffusion Implicit Models (DDIM) for faster generation**
